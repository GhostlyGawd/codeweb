Get started with codeweb — plugin, npx one-liner, or MCP server

Free & MIT-licensed. Runs entirely on your machine — no account, no server, no telemetry. Reads your code; never executes it.

  • Requires Node.js ≥ 22.
  • Zero required dependencies — an empty node_modules works.
  • A wasm grammar, ctags, and ripgrep are optional and can improve extraction.

Map without an AI agent

Run one command from your project directory. The npx command does not create a permanent installation.

## codeweb — ask the map before and after every edit
This repo is mapped by codeweb (a deterministic call/import graph; {{toolCount}} read-only MCP tools).
- Orient once per session: codeweb_brief. No symbol name yet? codeweb_find "<concept>".
- BEFORE touching a symbol: codeweb_explain (one card), then codeweb_context (edit window)
  or codeweb_impact (blast radius); codeweb_dependents lists EVERY user of it.
- Before writing a new function: codeweb_find_similar (does this exist?) and codeweb_placement.
- AFTER editing: codeweb_refresh {snapshot:true}, then codeweb_diff {} — fix any regression
  it reports before moving on.
- A stale answer names codeweb_refresh; "no graph found" names codeweb_map. Follow the remedy.

For a temporary evaluation, run the npx command and open the generated map.

Five-minute quickstart

From a cold repo to a queryable map

1 · Map it

Build the graph and the interactive report for a target.

node scripts/run.mjs ./my-app --out-dir ./my-app/.codeweb
# open ./my-app/.codeweb/report.html
2 · Query the graph

Ask what a change touches before you make it.

node scripts/query.mjs ./my-app/.codeweb/graph.json \
  --impact myFunction --json
3 · Guard the edit

Diff two snapshots and get a regression verdict.

node scripts/diff.mjs before.json after.json
# exit 1 on a new cycle, new duplication, or lost callers
4 · Gate the PR

Run the same verdict automatically on every pull request.

node scripts/ci-gate.mjs --base origin/main --target src

Or drop in the GitHub Action — see the CI gate.

Concepts

Five ideas that make the rest click

Node & edge

Every function, class, and method is a node; calls, imports, inheritance, and test links are edges. That graph is the substrate for every query.

Domain

codeweb clusters nodes into semantic domains. Use the domains to reason about subsystems across files. Cross-domain overlap identifies consolidation opportunities.

Overlap

Two nodes overlap when they do the same work. codeweb confirms overlap by comparing bodies and dismisses same-name functions with different bodies.

Blast radius

Everything transitively affected by changing a symbol. Ask for it before editing so you know what an edit can break.

The gate

A structural regression check: a change fails if it adds a cycle, adds a body-confirmed duplicate, or orphans a symbol. Pure removals always pass.

Severity

Each finding has a high, medium, or low confidence tier. The report highlights high-confidence rows so you can inspect actionable findings first.
